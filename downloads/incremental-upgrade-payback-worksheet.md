observations, game retention data, or measured results.

For this simplified model, the starting rate is 1 spark per tap and
0 sparks per second. Buying exactly one sharper pencil adds 1 spark per tap.
Buying exactly one routine adds 1 spark per visible, unpaused second.
All three paths use the same planned actions and make no further purchases.

## Do the three calculations

| Path | Calculation | Final balance |
| --- | --- | --- |
| Buy nothing | B + N | |
| Buy pencil, only if B is at least C | B - C + 2 x N | |
| Buy routine, only if B is at least R | B - R + N + T | |

- Largest final balance under these assumptions:
- Pencil payback relative to no purchase: C additional taps.
- Routine payback relative to no purchase: R visible, unpaused seconds.
- Routine balance minus pencil balance, if both are affordable:

- A tie between the two upgrades occurs when T = N + R - C.
- Important limitation: these payback counts exclude time spent earning
  the purchase price before the modeled start.

## Boundaries

- This sheet does not calculate player enjoyment, retention, or game quality.
- All modeled purchases occur at the start, if already affordable.
- No compounding, later upgrades, background progress, or offline earnings.
- A calculated winner is the largest **final spark balance** for the inputs,
  not a recommended design decision for every player.
- The guide and worksheet do not collect answers or require an account,
  upload, AI tool, or analytics service.
