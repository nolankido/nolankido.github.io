# Poker resources: batch 003 and recovery

Reviewed October 7, 2026, Pacific time. Publication is established by the merged pull request and live checks, not this document alone.

## Measured scope

82 existing listings plus 26 new destinations gives 108 resources in 13 categories. All 26 additions offer the listed public material free; the complete directory has 91 Free, seven Mixed and ten Paid listings. Distinct normalized destination hostnames increased from 46 to 62. Hostnames are a reproducible diversity indicator, not a count of independent ownership groups.

The prior 82 records were preserved without refreshing their review dates. This pass inspected the public text, catalogue, documentation or repository landing page for the 26 additions. No videos were watched to completion, paid lessons purchased, binaries installed, software calculations validated, or linked rulebook PDFs analyzed. A listed product manual is not a security or accuracy endorsement.

## What makes this more useful

Six compact, expandable starting paths connect concrete reader questions to existing catalogue IDs. The title and access label come from the same listing records, not a second manually copied directory. All routes retain native anchors, keyboard access and a no-JavaScript reading path. A starting-point link clears active filters so the destination cannot remain hidden by a previous search. The links do not inflate the count of unique external destinations.

The six questions concern learning the game, reviewing tournaments, studying cash games or Omaha, watching hand explanations, finding official event information, and inspecting tools or datasets. These are editorial starting choices, not objective rankings. Support links are also reachable near the directory controls instead of only at the bottom.

Search now indexes visible card text once. The page no longer repeats each description and caveat in a hidden search attribute. This reduces duplicated HTML without removing any public description, limitation, access label or search feature. A browser test must establish that title, publisher, notes and new topics remain searchable.

## Quality bar for the next pass

A useful destination should have identifiable provenance, a distinct reader use, inspectable access conditions, a scoped description, and no duplicate destination. Prefer sources that explain inputs and assumptions. Preserve disagreements where useful rather than presenting a vendor's model as universal. Historical sources require a visible period label. A 200 response does not replace content review.

Internet-wide best status has not been measured. Assess progress by additional useful questions answered, original-source diversity, successful reader paths, corrections and actual review evidence. Do not trade those for a round-number link quota.
