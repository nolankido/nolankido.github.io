# Poker viewer library

Adds seven beginner-facing guides under /poker/: holdem-basics, hand-rankings,
betting-and-pots, tournaments, poker-math, glossary, and viewer-questions.
The existing start-here page is the directory; all earlier anchors remain valid.
The collection contains 48 glossary entries, ten visual hand-ranking labels,
four independently checked showdowns, a complete fictional hand, side-pot and
probability examples, and 26 native answer disclosures (16 practice prompts
and ten viewer questions). A compact Markdown viewer reference is downloadable.

These are educational guides, not recorded episodes or a strategy solver.
All examples are fictional. References were checked October 5, 2026, including
the 2026 Poker TDA rules. Commercial reference sites are not endorsements.

The Technology-first homepage and non-Poker page bytes remain unchanged.
Poker guide sources and shared Poker navigation are updated. The actual content
catalog remains empty until approved episodes are provided. No media profiles,
footage, player identities, or real results are inferred. No runtime scripts,
tracking, accounts, external images, or database are introduced.

The existing manifest, build, sitemap, Poker RSS and live verifier include the
new pages. Their Article metadata uses explicit dates. The general Notes feed,
contact JavaScript, base stylesheets and domain configuration are preserved.
The test suite independently checks rank categories, five-of-seven comparisons,
unique cards, call/side-pot conservation, exact draw probabilities, and links.
Browser tests expand answers, operate a disclosure with a keyboard, apply reader
text spacing, traverse guide links and verify the new download bytes.

Run all checks in README before releasing. Automated accessibility success is
not certification; inconclusive checks still need interpretation. No real form
submission, inbox test, or live video validation is performed by these tests.
