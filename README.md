# Nolan Kido personal website

Public source for the personal website at **nolankido.com**, hosted with GitHub Pages.

## Public structure

- `/` — home
- `/about/` — selective introduction
- `/notes/` — public writing archive
- `/bio/` — reusable biography
- `/contact/` — protected contact form
- `/card/` — networking card for QR/NFC sharing
- `/privacy/` — privacy information
- `/feed.xml` — RSS feed

## Design

The site uses the **Quiet Signal** visual identity: restrained editorial layout, warm ivory, basalt, deep green, muted brass, serif display typography, and intentionally limited public detail.

## Technical setup

- Static HTML and CSS
- GitHub Pages hosting
- No third-party fonts
- No behavioral analytics or advertising trackers
- Minimal external runtime dependencies
- Canonical domain: `https://nolankido.com/`

Operational notes, automation rules, and private maintenance context are deliberately kept out of this public repository.
