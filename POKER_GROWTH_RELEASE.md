# Poker publishing foundation

This release changes the Poker subsection while preserving the approved
Technology, Poker, Creative Work landing page and all non-Poker page bytes.

## Public changes

The Poker overview connects a viewer guide, the existing worked hand review,
and a study desk with private-use hand and session worksheets. The overview keeps
the original `/poker/#study` anchor. A Poker-only feed starts with the two reading
guides, without changing the general Notes feed. No real episode, footage, player,
result, channel URL, or private project is introduced.

## Growth workflow

An empty, public-only catalog supports approved episode companions, reconstructed
or illustrative hand reviews, and tournament stories. The builder generates stable
pages, optional chapter links and local images, spoiler disclosures, related links,
the Poker collection, sitemap, and separate feed. Text is escaped. There are no
runtime databases, video embeds, new scripts, remote thumbnails, or account gates.

The draft helper writes unapproved templates outside the public checkout and refuses
to overwrite files. The publishing guide describes final approval and signed-out
video checks. Syntax validation is not fact-checking or privacy protection.

## Verification scope

Regression tests preserve the homepage and non-Poker pages, validate catalog inputs,
exercise populated and empty collections, and test the real generated reader flow
with synthetic fixtures in a temporary copy. Browser tests cover responsive layouts,
keyboard access, disclosure controls, and exact worksheet downloads. Existing contact
failure-recovery tests remain mocked. Inbox delivery is not tested. Automated
accessibility results require manual interpretation, especially inconclusive checks.
