# Poker rules reference consistency

Reviewed October 16, 2026 UTC against production commit
`bc0d6ae893e59b89aaa63fd7c6aa58be78045fae`.

The official TDA rules page identifies 2026 Rules, Version 1.1, September 21,
2026. The directory and four older guides still cited version 1.0, while the
newer first-decision and first-session guides already identified 1.1.

The official version-history announcement describes the 1.1 release as minor
edits and clarifications, including internal cross-references. This pass read
the current primary text for floor discretion, player responsibilities,
declarations, devices, showdown, clocks, heads-up positions, raise increments,
oversized chips and reopening. The existing worked examples remain consistent
with the inspected current rules. This is not a line-by-line comparison of
archived 1.0 and 1.1 documents, a review of every addendum or translation, or a
claim that TDA rules govern every cash room.

The existing `tda-rules` resource record now owns the version metadata. Current
citations in six guides, resource cards, search passages, quality reporting and
the downloadable directory derive from it. The TDA review date alone advances.
The other 145 resources, historical batch records and historical rulebook
listings retain their existing evidence and dates. Four corrected older guides
receive an explicit October 16 revision; the two newer guides record the TDA
reference recheck alongside their earlier overall reference dates.

New regression checks change a synthetic edition/version in memory and verify
propagation without publishing the fixture. A digest-bound adapter retains the
exact predecessor for older preservation tests; unrelated edits remain visible.
The prior test that pinned the live directory to September 7 now checks the
canonical current record while keeping Batch 002's historical account intact.

Executed checks and publication verification belong in the pull request. No
learner-comprehension, traffic or commercial outcome is claimed by this change.
