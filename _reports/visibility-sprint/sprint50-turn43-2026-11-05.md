# Turn 43: make monthly search evidence usable without a paid connector

Reviewed November 5, 2026. Starting `main` commit: `a2b4059e59325b9d142fbf50a540213b1a25fa0e`.

## Decision

The existing [SEO and GEO measurement protocol](seo-geo-measurement-v1.md) carefully separates Google Search clicks, Google's generative-AI impressions, assistant referrals, and sampled answer citations. It does not contain a runnable local method for summarizing Search Console's exported page and visible-query rows. Authenticated search data was not available for a defensible outcome claim during this turn. A free, explicit CSV method is more useful than another unsourced declaration that search visibility improved.

This turn adds one offline Python summarizer, synthetic regression tests, and an explanation beside the public Technology visibility case. It adds no tracking event, analytics dashboard, search provider subscription, scheduled task, CI workflow, or generated article URL.

## Improvement

1. New [`downloads/gsc-monthly-local-audit.py`](../../downloads/gsc-monthly-local-audit.py) reads locally exported Search Console Web-search Pages CSV, optional Queries CSV, and optional combined Query + Page CSV. It does not fetch remote data, import third-party libraries, or write any file. Private CSVs are supplied only by whoever runs it locally.
2. It groups observed page rows into Technology, Poker, Living Well, Creative, and Other. It excludes domain lookalikes and reports excluded-row counts. Where visible query data exists, it counts recognizably branded searches for Nolan Kido and the full AI Works Human Decides phrase separately, explaining that the categories can overlap.
3. It calculates visible, nonbranded Technology query clicks **only** from genuine combined Query + Page rows. A Pages table cannot be joined to a separate Queries table to reconstruct that number. Empty or missing exports return `null` rather than an invented zero; property-level search clicks and impressions are always left `null` for direct recording from the Search Console chart.
4. The JSON output contains only aggregates, row counts, declared date windows, and explanatory limitations. It never echoes original queries, full URLs, or CSV paths in successful output. Actual private data is neither committed nor shown in this release.
5. The canonical Technology page now offers the script and [its manual export protocol](seo-geo-measurement-v1.md#offline-local-csv-summary) adjacent to the existing `#site-visibility-limits` evidence boundary. The link was added to both the source and the generated public page without changing the existing URL, article date, or shared identity schema.

## How to use privately

After choosing the exact whole month and **Web** search type in an owner's verified Search Console property, export Pages CSV, optionally Queries CSV, and record the true selected date range privately. On Windows, from the repository root:

```powershell
py -3 downloads/gsc-monthly-local-audit.py --month 2026-10 --pages "$env:USERPROFILE\Downloads\Pages.csv" --queries "$env:USERPROFILE\Downloads\Queries.csv" > "$env:USERPROFILE\Documents\gsc-2026-10-private.json"
```

The paths are illustrative. The optional combined dataset must contain `Query`, `Page`, `Clicks` and `Impressions`, and can be supplied with `--query-pages` when legitimately available. The tool does not prove the export's month or completeness. Review any resulting private figures against the first-party chart totals and Search Console reporting delays; do not commit the CSV or JSON output to this public repository.
