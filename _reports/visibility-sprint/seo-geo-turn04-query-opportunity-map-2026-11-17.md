## Prioritization method

The order below is an editorial decision, not a computed keyword score. Favor (a) the reader's ability to complete a valuable real task; (b) unique, publishable first-hand evidence; (c) practical feasibility without new spending or private data; and (d) a narrow answer that gives a reason to choose this site over a broad generic guide. Observed demand could override the order **only after it is available**. A query phrasing is an intent exemplar, not an exact Search Console keyword.

### De-duplication and excluded clusters

- **One canonical answer per task.** AI reply drafting maps to `/technology/local-ai-review-replies/`; the separate `/technology/review-reply-evidence-audit/` proves the narrower audit task. No second page for "AI review response tips" wording.
- **Two legitimate distinct 10BB questions.** The short-stack guide addresses tournament survival decisions; the satellite page addresses approximately equal-prize seat equity. Do not merge their examples or misstate one as the other.
- **Poker math vs live preparation.** A worked equity calculation is different from a first-event etiquette/checklist task. Both can link to basics without becoming thin duplicates.
- **Person vs project.** `/about/` answers identity; `/projects/` provides artifact inspection. Avoid duplicating entire biographies or case studies in both.
- **Creator evidence vs player profile.** The `/poker/nolan-kido/` profile is the player-identity reference; the Portland Meadows episode is an experience-specific source. Connect the two with native links and respect gross prize and deal caveats.
- **Living Well:** no dedicated expansion ranked in this turn, because no observed query demand or unique higher-impact gap was available. Do not interpret this as negative search performance.
- **Existing question map:** preserve all prior creative and AI questions as candidate intents; this dated layer selects the next twelve priorities, not a deletion list.

## Frozen assistant-question panel, v1

**Canonical file:** [`assistant-answer-panel-v1-2026-11-17.csv`](assistant-answer-panel-v1-2026-11-17.csv). It has **25 exact user prompts**, of which **20 are nonbranded (`NB01` to `NB20`)** and **five explicitly name Nolan (`BR01` to `BR05`)**. Each row specifies the answer task, category and expected first-party landing path. All listed destinations existed in the 224-URL public sitemap on the assessment date.

**How to execute a later evaluation without bias**

1. Freeze the CSV's exact prompt text and version before the first run. Do not add Nolan's name or domain to a nonbranded prompt. Do not reword only the misses.
2. For each assistant/search product, start a **fresh conversation with no prior site context**. Use one consistent instruction for all 25: "Answer the question directly. Cite accessible public sources with links where available. State uncertainty rather than inventing facts." Record whether browsing/web citations were enabled and the product/model/version, date, country/language and account/personalization state. A remembered Nolan conversation invalidates a nonbranded discovery test.
3. Record the full answer and **actual cited URLs** in a dated private run sheet. Score each prompt separately for: `first_party_cited` (1 only for an explicit source URL or citation to `nolankido.com`), `first_party_mentioned` (1 if named but no citation), `answer_correctness` (verified/partial/incorrect/unverified), and `task_completed` (yes/partial/no). Use `NA` for a run that could not be executed, **not zero**.
4. Count citations to the expected canonical destination separately from citations to a different on-domain page. Normalize protocol, trailing slash, fragments and common URL tracking parameters; preserve redirects and raw source URLs in the audit record. An answer that names Nolan in text but cites someone else **does not count as a Nolan citation**.
5. Check attributed claims against the live cited source. Flag unsupported wins, solver claims, personal details, event dates or invented video scenes even if a URL appears. Do not favor a citation that answers the wrong reader question.
6. Keep a per-prompt result and paired aggregate across the **same 25 prompts**. Report `x/20` nonbranded and `y/5` branded cited if all ran; if some failed to run, show eligible denominators. Preserve historical runs and create `v2` only with a dated reason after evaluating v1; never silently revise past questions.
7. Run the panel again at Turn 24 with comparable settings if possible. It measures **observable answer appearances in a specified test environment**, not all AI systems' indexation, user traffic or general probability of citation.

**Suggested run-sheet columns:** `run_date_local,platform,model_version,browsing_enabled,personalization_state,prompt_id,raw_answer_location,raw_cited_urls,expected_path_cited,other_site_path_cited,first_party_mentioned,answer_correctness,task_completed,review_notes`.
