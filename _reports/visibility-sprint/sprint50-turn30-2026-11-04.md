# Visibility sprint Turn 30: A public evidence-by-type index

Reviewed November 4, 2026. Base commit: `c259d366176f3411e89777646135262178cc75b3`.

## Why this is the next highest-leverage improvement

The user's three goals are search and generative-AI visibility for Nolan Kido, immediate credibility when someone reaches the About page, and a coherent identity connecting practical AI, technology, research, poker and other interests.

The website already contains a strong mix of content. That variety is a source of confusion when the same navigation presents a functioning browser calculator, an archived AI-assisted draft, a peer-reviewed accounting paper, a poker narration, a reflective essay and a proposed exercise without explaining how they differ as evidence. A reader might mistakenly treat an application demonstration as a measured client result, an essay as a research finding, or a paper hosted by MIT as evidence of an MIT appointment.

**Decision:** add one concise, visible evidence map to the existing Start Here page and connect the About page's credibility section directly to it. Do **not** create a new canonical index page, fabricate ratings or testimonials, generate duplicate case articles, or claim a search-ranking lift.

## Published entry points

- Primary index: `https://nolankido.com/start-here/#evidence-types`
- Credibility path: `https://nolankido.com/about/` links directly to the new index from the already sourced "A few things you can verify" section.

The new index contains seven distinct proof types, each linked to an existing authoritative original, and labels what the example does and does not establish.

| Type | Example | Specific evidence | Excluded overclaim |
| --- | --- | --- | --- |
| Working browser tool | [AI time-savings calculator](https://nolankido.com/technology/ai-time-savings/) | Arithmetic on reader-supplied preparation, execution, review and upkeep assumptions | Not recorded time savings or an AI model call |
| Public application and demonstration | [Review Reply Writer](https://nolankido.com/technology/local-ai-review-replies/) and [Preflight](https://nolankido.com/technology/ai-book-continuity-checker/) | Inspectable software, source links, archived tests and mistakes | Not verified client adoption or universal production reliability |
| Recorded AI-assisted task | [Notes-to-action checklist](https://nolankido.com/technology/organize-public-notes/#notes-repro-audit) | Actual original input, eleven output rows, deterministic scoped check | Not proof starting claims were true or work was completed |
| Peer-reviewed scholarship | [2012 Journal of Accounting Research publication](https://doi.org/10.1111/j.1475-679X.2012.00447.x) | Accounting paper coauthorship and publication | Not an MIT appointment, AI research claim or current job |
| Tournament record and first-person account | [Nolan Kido poker profile](https://nolankido.com/poker/nolan-kido/) | Independent results where cited, separately identified personal video stories | Not net poker profitability or verified details of every hand |
| Essay | [Keep the Judgment](https://nolankido.com/notes/keep-the-judgment/) | Published viewpoint and explanation of an AI practice | Not a controlled study, credential or performance evaluation |
| Proposed exercise | [Living Well field notes](https://nolankido.com/living-well/field-notes/) | Optional ideas and proposed exercises | Not an observed personal experiment or measured outcome |

This is an **evidence directory**, not a ranking of accomplishments. It deliberately preserves the specific primary sources and their caveats.

### Accessibility and technical discipline

The index originally had a wide table draft, but Start Here does not load the `project-table-scroll` stylesheet used elsewhere. Publishing a four-column table on mobile would risk horizontal overflow and cramped text. The reviewed version instead uses an ordinary seven-item `ul` in the page's existing task-list styling, with clear native anchors and visible descriptions. No new stylesheet, JavaScript, iframe, form, model call, UI widget, or API request is required.

Start Here is not eligible for inclusion in the local Find page's section-heading index. The existing Find data is therefore **not** modified; there is no inaccurate or stale added Find heading to reconcile. The native `/start-here/` page is already available through the site-wide Start Here link, and the About page adds the contextual deep link.

It does not prove an increase in Google/Bing impressions, inclusion in generative-AI results, stronger reader confidence, or a change in visitor behavior. Such improvements require separate actual measurements or outside-reader comprehension tests.
