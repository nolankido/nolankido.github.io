# Turn 118: Keep manual-copy instructions visible at extreme reflow

Date: November 11, 2026

Baseline: `3aa78aafcb47b114046f50e4ccf1d992c9058c02`

## Observed reader problem

Turn 117 moved the answer-checking handoff beside the export status. The
remaining accessibility check was manual text selection on an extremely
narrow, short viewport. Connected Chrome inspection of the current public
page at **160 by 568 CSS pixels** revealed that the native full selection
worked, with all **1,454 fictional characters** selected and the beginning
of the text visible at **465px**. Save and Print alternatives were also
visible. However, the standalone “Selected, not copied” instruction was
scrolled almost entirely above the viewport: its bounds were **-163 to
43px**, while the fallback panel began at **55px**. The panel itself did
not say how to perform native Copy. No horizontal overflow occurred.

This test is a severe-width reflow proxy, **not** proof of actual 200%
browser text enlargement. A connected Chrome zoom keyboard command did
not change viewport or text metrics. The existing local headless
Chromium restriction also remains unresolved.

## Improvement

- Replace the fallback panel's generic “Copy not working?” heading with
  an explicit, concise instruction: **Selected, not copied. Ctrl+C,
  Cmd+C, or touch Copy.** The instruction stays beside Save and Print
  actions even if the separate selection cue scrolls above the screen.
- Keep the instruction short so it occupies approximately the same space
  as the previous heading. Preserve the **44px** action minimum, the
  independent confirmation warning for downloads/PDFs, and the full
  original `aria-label` values.
- Do not change selection, focus, text contents, native clipboard actions,
  print, download, link routes, browser storage or network behavior.
- Extend the optional **200% text-enlargement browser harness** to select
  the full brief after returning from the same-page answer-checking
  guide, verify the fallback panel contains native Copy instructions,
  and verify the full selection and absence of horizontal overflow.
- Add three focused source/build/behavior regression tests, update the
  previous fallback wording contract and register the new test in the
  manually invoked local release checklist.
