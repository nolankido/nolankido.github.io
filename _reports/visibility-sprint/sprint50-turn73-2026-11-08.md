# Turn 73: Verify the complete published brief-check history

Date: November 8, 2026

Baseline: `99755a0ac48f5c8a41ef7e80962c23d49a9ca445`

## Observed problem

The optional `_tests/test_brief_check_history.py` module originally ran 11
tests with seven failing assertions. It read seven current website files and
used the visibility-sprint predecessor adapter to try to reconstruct their
October 2026 bytes. Five files had independently changed again, so the old
successor hashes did not match. This also meant a test of corrupt reverse
spans failed to enter the intended reverse-span validation path.

The historical parent `427f258ad895cfc736d3d29944347ea584f04826` has two
direct child commits. The sibling
`6ec6e4b64669d9c6cfb38f6b45957ee40f57efe3` does **not** contain all
seven published successor files. The reviewed, merged release
`2aae4923318c0028d98266d78f6e4aabea295387` does. The release's manifest,
source, CSS, JavaScript, Find, sitemap and compiled task-brief page were
checked individually against the existing exact SHA-256 change ledger.

## Improvement

- `_tests/test_brief_check_history.py` now reads precisely the seven original
  successor files from that complete merged Git release, through
  `_tests/reviewed_release.py`, which verifies the full Git commit and each
  independently pinned Git blob SHA-1 before returning bytes.
- All existing predecessor SHA-256 hashes, reverse-span integrity checks,
  metadata checks, idempotence checks, unknown-file safeguards and deliberate
  mutation tests remain active and unchanged.
- Added an independent check that the reviewed successor commit's Git parent
  is the ledger's actual parent. For each of seven paths, it compares the
  reconstructed predecessor byte-for-byte with `git show` of that parent and
  verifies its separately recorded SHA-256.
- Added a negative regression proving that the sibling child commit with an
  incomplete source/CSS/JavaScript/generated-page set cannot masquerade as
  the reviewed seven-file successor.
- No production history adapter, golden ledger file or public build source was
  altered. A later change to the live website does not silently change this
  older historical contract.
