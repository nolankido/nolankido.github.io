# Turn 120: Remember failed exports during manual-copy recovery

Date: November 11, 2026

Baseline: `4b8d2ecc007068e659d111e5000e77c2969ddef5`

## Observed logic problem

The Task Brief builder offers a selected-text fallback with Save and Print
alternatives when a clipboard operation is denied or an export fails. The
previous `showExportAlternatives` implementation hid only the action that
had **just** failed. If printing failed and the offered text download also
failed, the Print action returned to the nearby fallback panel despite its
known failure. The reverse failure order had the same defect. This is a
reproducible code-path problem and deterministic test case, not a claim that
both operations failed in a visitor's real browser.

## Improvement

- Remember native print and text-download failures for the currently
  assembled brief. If one fails, keep the other available. If both fail,
  hide both failed buttons rather than offering an unsuccessful loop.
- When both fail, name the remaining full-text selection and native
  Ctrl+C, Cmd+C or touch Copy route immediately beside the text. The status
  explicitly says that no copy or file save has been confirmed and asks the
  reader to paste into their own notes to verify.
- Preserve the existing correction when the text selection becomes partial,
  and restore a complete selection through **Select text manually**. A
  detected native Copy event still does not claim clipboard success.
- Reset the remembered failures when the draft is edited or a new brief is
  assembled. Existing plain-text output, navigation, print and file content,
  headings, resource URLs and source disclosure remain unchanged.
- Add a dedicated Node-backed regression for both failure orders and
  selection/reassembly transitions. Update the older export test's now
  obsolete expectation and include this new test in the manual release suite.

No new tracking, remote request, browser storage, scheduled task, dependency,
or GitHub Actions workflow is introduced. The public page retains its November
11, 2026 content revision date.
