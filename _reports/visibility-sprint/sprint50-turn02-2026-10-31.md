## Implemented change

- `_tests/diagnose_live_crawl.py`: a separate read-only diagnostic runner for 14 priority routes or all 495 public targets. It reuses the original verifier's exact-byte checks, limits concurrency, retries failures within a bounded count, prints one summary, and separately probes unresolved transport errors for a short reason. A separate HTTP 200 does not turn an exact-byte failure into a pass.
- `_tests/test_live_diagnostics.py`: two network-free tests for controlled retries and for retaining a failed result when a separate diagnostic GET later responds.

The production `_scripts/check_live.py` and its prior regression tests remain unchanged. Historical source fingerprints and release evidence are intentionally protected by the repository's integrity tests. This improvement belongs in the diagnostic test utilities, which are outside the published site.

No production page, canonical, schema, noindex directive, redirect, feed, form, analytics setting, or third-party service was changed in this technical hygiene turn.

## Reproduction and verification

Run locally from the repository root:

```sh
python3 _scripts/build.py --check
python3 _scripts/check_search.py
python3 -m unittest discover -s _tests -p 'test_site.py' -q
python3 -m unittest discover -s _tests -p 'test_search_visibility.py' -q
python3 -m unittest discover -s _tests -p 'test_live.py' -q
python3 -m unittest discover -s _tests -p 'test_live_diagnostics.py' -q
python3 -m unittest discover -s _tests -p 'test_visibility_sprint_history.py' -q
python3 -m unittest discover -s _tests -p 'test_time_print.py' -q
python3 _tests/diagnose_live_crawl.py --scope priority --attempts 2 --interval 2 --workers 2
```

The deterministic site, search, live-checker, and new diagnostic tests passed during this turn, with search-audit output unchanged and 229 generated files matching source exactly. The frozen historical visibility-sprint and production-inventory test groups also passed (nine and four tests, respectively). The `test_search_visibility.py` test requires a writable temporary fixture directory, which was initially unavailable in the restricted shell; it passed after explicitly authorized temporary-file access.

The bounded independent priority live check passed **14 of 14 exact-byte targets**, with zero unresolved failures, including the home, About, Bio, Technology, Poker, three project cases, robots, sitemap, social preview, and expected custom 404 response. This is an observation at the time it ran, not a deterministic unit test. The broader 495-target first attempt had transient transport errors and did not establish a whole-site live pass; those URLs should not be called HTTP 404s based on that attempt.
