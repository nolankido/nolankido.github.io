# Turn 141: Keep direct AI project-example arrivals visible

Date: November 12, 2026

Baseline: `79018db1cc05a1a07fd0daf82667983271b94b8c`

## Observed problem

The homepage and Technology hub link directly to the evidence examples in
Preflight (`#continuity-example`) and Dinner on Time (`#dinner-demo`). Both
pages had ordinary native headings, with no visible cue identifying which
section a fragment link selected.

In the live Chrome browser at a 390-pixel viewport before this change:

- Preflight's example heading settled around 180 pixels from the top, below
  a roughly 149-pixel sticky header. It had no target outline.
- The Dinner on Time demo heading sometimes settled around 115 pixels from
  the top, partly obscured by that header. A separate `#dinner-decisions`
  arrival settled around 180 pixels and was already visible. Both had no
  target outline.

These were direct browser observations of a navigation defect, not evidence
of lost readers, a traffic problem or general cross-browser behavior.

## Improvement

- Add page-scoped red `:target` heading outlines for Preflight and Dinner on
  Time, consistent with the previously reviewed Review Reply Writer cue.
- Reuse the existing small arrival-correction script for all three project
  pages. It only accepts a case's own `reply-*`, `continuity-*`, or
  `dinner-*` heading fragments, waits for the page and fonts to settle, and
  scrolls only if the selected heading is hidden or near the bottom.
- Preserve native fragment URLs, keyboard focus, ordinary scrolling and
  controls. Keyboard, pointer, wheel, touch and page-exit events cancel a
  pending correction. The script makes no network request and stores no data.
- Register the script with content-hashed URLs only on the three cases.
  Rebuild the other ten stylesheet-consuming public pages and the two
  independently generated articles so every link references the updated
  stylesheet. No article content, date, canonical, schema fact, user record,
  paid service or scheduled workflow changed.
- Extend the existing Review Reply Writer regression check to permit the
  reviewed additional scopes while keeping its original negative controls.
  Add five focused Turn 141 tests for native sources and destinations,
  versioned files, scope, cancellation safeguards, metadata and mutations.
