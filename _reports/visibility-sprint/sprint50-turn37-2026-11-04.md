Date: November 4, 2026. Website: `https://nolankido.com/`. Repository: `nolankido/nolankido.github.io`.
Starting `main` commit: `6a5d017d49722f9ae06126761098c3e42244bf30`.

## Purpose and scope

The sprint aims to make Nolan Kido's public identity, practical AI work and outside interests more discoverable and credible. Following Turn 36's About orientation links, the next independent improvement is to protect readers from broken internal routes and section links as that evidence library expands. The owner-approved portrait and professional timeline require source material; independent reader or screen-reader research needs consenting participants. Neither is simulated here.

The connected GSC Wizard quick-wins request returned `payment_required` because its third-party trial has expired. No subscription was activated, no charge was incurred, and no confidential search data was obtained. This turn uses repository-local evidence without paid services, GitHub Actions or scheduled jobs.

## Findings before repair

- There are **206 generated public HTML pages**, with **13,894 internal links** and **3,986 links containing URL fragments** in the exact GET inventory.
- A naive anchor-only check flagged 91 references. Of those, **90 are intentional Poker Finder state fragments** such as `#topic=learn&kind=resource`; the Finder's public JavaScript restores their filter settings. They are not DOM IDs. There were no duplicate IDs on the generated pages.
- One linked Python download, `/downloads/reply-audit-boundary-probes.py`, was absent from the release script's exact-byte target inventory. The source file existed and the live server independently returned HTTP 200 with matching bytes at the start of this turn. The missing inventory entry was a verification gap, not evidence of a dead public link.

## Changes

1. Add `_scripts/check_internal_links.py`, a network-free checker over the local public GET inventory. It parses every public HTML `<a href>`, resolves relative, root and same-origin absolute links, verifies destinations, checks `id` targets, and rejects duplicate IDs.
2. Treat Poker Finder's special state fragments as valid only on its actual route with the published `topic` and `kind` options, the one permitted `free=1` state and the existing JavaScript fragment restoration code. Unknown settings, duplicate keys or missing Finder support still fail.
3. Include `downloads/reply-audit-boundary-probes.py` in `_scripts/check_live.py` so the public release inventory checks its exact bytes, just like the companion case and other downloadable proof assets.
4. Add both the checker and its synthetic negative-control tests to `_scripts/local_release_checks.py`. The tests inject malformed links in memory and never alter production content or call the network.
5. Preserve earlier exact-byte historical checks through a bounded predecessor map. Only recorded, byte-identical Turn 37 edits can be rewound for older test contracts; unexpected edits remain visible and fail.

No live page copy, canonical route, external identity assertion, Person schema, publication date or user tracking was added or changed.

## Limits and subsequent decision

The checker confirms that the repository-generated pages link to registered local public targets. It is not a browser click-through test, a live crawl of every route, a screen-reader usability audit, or a guarantee that external links remain accessible. The successful search/indexing and AI-assistant citation outcomes that motivated the sprint remain to be measured from independent evidence. The next sprint decision should be informed by first-party performance or a consenting outsider's comprehension once available, without inventing either.
