## Release-based IndexNow notifications

`_scripts/submit_indexnow.py` compares two explicit Git commits and selects meaningful changes among their canonical sitemap URLs. A normal invocation is a network-free dry run. External submission requires `--submit`.

The main-branch workflow runs the notification only after the exact public-response check succeeds for the current commit. The submitter also checks the published key, matching release, and affected public responses before contacting the fixed IndexNow endpoint. It restricts submissions to this site's canonical URLs and bounds transient retries. A notification failure has its own warning and receipt; it does not undo a verified website deployment.

The verification file at the domain root establishes control for IndexNow. It does not grant access to a hosting account. Its exact public bytes are part of the release verifier. Notifications send public URLs, not visitor data, private worksheet contents, or credentials. The workflow retains a receipt artifact for 30 days.

Each ordinary push compares its actual predecessor with the deployed commit. The setup does not submit the entire existing sitemap or retroactively resubmit older releases. Earlier cases continue to have accurate sitemap dates and gain the new internal links described above.

HTTP 200 records receipt. HTTP 202 records receipt with key validation pending. Neither result proves crawling, indexing, ranking, or citation by an AI system. These distinctions follow the [IndexNow protocol](https://www.indexnow.org/documentation). The [official FAQ](https://www.indexnow.org/faq) recommends meaningful change notifications alongside sitemaps and discourages retroactive or unnecessary submissions.

## Visibility limits and next evidence

Clear links, accurate titles, relevant filters, and change notifications improve how the published work can be found. They do not supply measured search demand or establish that visibility increased. Google's [current generative AI guidance](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide) emphasizes useful distinctive material, clear organization, and established SEO fundamentals. The strongest remaining content opportunities still require real source material: a personal local-AI run, matched workflow comparison, complete task timings, firsthand poker account, completed Living Well observation, or approved travel artifact.
