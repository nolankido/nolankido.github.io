## Observed presentation mismatch

Nolan's stated brand phrase is **AI Works, Human Decides**, including the comma.
Before this turn, the homepage hero, About introduction, Technology method
heading, related judgment essay, generated biography text, identity structured
data, search titles and sharing descriptions mostly used **AI Works Human

## Improvement

- Used **AI Works, Human Decides** consistently in the primary Home, About,
  Technology and judgment essay copy, titles, meta descriptions and JSON-LD
  page descriptions.
- Corrected the central `site.json` tagline and biographies, the public Person
  description, Home and About sharing-image alternative text, and the repository
  README's first line. Generated bio and card pages and TXT bio downloads now
  reflect the same identity language.
- Corrected the Technology path generator's independent title and description
  constants so a later rebuild cannot revert that page's search metadata.
- Left historical release notes, their original quotations and source-revision
  wording untouched. Preserved URLs, fragment identifiers, existing identity
  assertions, page dates, RSS dates and the sitemap rather than implying a
  content-freshness event from editorial punctuation.
- Added an offline regression that checks four canonical page titles,
  descriptions, structured data and visible headings; downloads, identity
  JSON-LD, sharing descriptions, README, sitemap dates and deliberately broken
  metadata examples. Added the regression to the manual local release checks.
  Older current-page tests now expect the agreed phrase while their archived
  SHA-gated release records retain their original content.

The static generator rebuilt 231 files and changed 14 generated outputs,
including the main four pages, indexes and biographies that reuse those
descriptions, combined and Technology feeds, and the public identity JSON-LD.
No photo or graphic file was changed. No new tracker, external service,
subscription, schema claim, testimonial or GitHub Action was introduced.
