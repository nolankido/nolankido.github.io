# Turn 133: Put the public evidence first on About arrivals

Date: November 12, 2026

Baseline: `6a834c4b124ba8231f6a4713826c4ac491cc7973`

## Observed reader path

Turn 132 connected three public AI case studies directly to
`/about/#about-evidence-title`. The target already existed, had a native
heading, stable ID and desktop/mobile scroll offsets, and contained three
source-linked cards. However, the cards followed a long introductory
paragraph, delaying the concrete evidence after an incoming fragment jump.
The heading also had no visual `:target` distinction to identify the linked
destination. This is an inspectable layout and CSS observation, not evidence
of poor visitor satisfaction, traffic loss or search performance.

## Improvement

- Placed the three existing evidence cards directly after the **A few things
  you can verify** heading. Moved the complete explanatory paragraph just
  below them, retaining its original wording, references and caveat.
- Added a red two-pixel outline to the existing About heading only when it
  is the native URL fragment target. Kept its pre-existing responsive
  scroll offsets, keyboard navigation and no-motion preference intact.
- Preserved all three evidence types, source links, claims and limit notes.
  This does not add a new credential, publication, professional history,
  current location, success rate or business-performance statement.
- Kept the stylesheet scoped to About and content-versioned by the existing
  build. No new runtime script, tracker, external service, GitHub Actions,
  scheduled task, canonical change, RSS update or artificial freshness date.
- Added four focused tests covering document order, case-to-About inbound
  anchors, honest evidence limitations, visible scoped target styling,
  deterministic output, dates, and deliberately damaged fixtures. Registered
  the tests in the local manual release checklist.

## Verification

- The primary builder regenerated 231 files; precisely one public HTML page
  changed (`about/index.html`) in addition to the scoped source and CSS.
  Deterministic rebuild produced zero drift.
- Turn 133 focused tests: **4/4 passed**, including negative controls.
- A local Chromium visual check was attempted at 320, 390 and 1440 pixel
  widths but the browser process failed to start because its local singleton
  socket was denied by the execution environment. No browser rendering,
  touch behavior, or screen-reader verification is claimed.
- Complete local release checklist: **68/68 groups passed**, with no GitHub
  Actions invoked. The internal-link audit checked **14,008 links across 207
  HTML pages** with zero issues. Search metadata checked **202 sitemap URLs**
  with no errors, and HTML5 parsing checked **207 pages** with no failures.

These checks cannot measure clicks, reader trust, indexing, AI-answer
citations or the causal effect of moving the evidence cards.
