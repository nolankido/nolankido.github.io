# Turn 85: Verify the local laptop guide history from its original Git release

Date: November 9, 2026

Baseline: `dcd2b1b774de8da600683043db5e12458141475c`

## Observed issue

The optional `_tests/test_turn08_laptop_history.py` module had 24 failing
assertions. It tried to derive the original November 2 local-AI laptop
guide release by partially reversing several newer website changes in
today's Technology, Find, RSS, scripts and tests. Unrelated later edits
made these current blobs differ from the exact released successors, so
the strict historical adapter appropriately declined to rewrite them.
The file-inventory assertions also assumed that today's added-file
copies retained their original release digests. These fixture problems
were not evidence that the current public laptop article was broken.

## Correction

- Pinned the original local-laptop release
  `fa6a2f7429df991bcea0ef4f204b6e1ec95238da` and its direct parent
  `546dde1820e042039db4e22baf2cbd389f944714`, with release tree
  `8027763f346b80f3d2c81ffcdc50efa22d3d072e` and parent tree
  `35d0fc7d2b7651d2ea6c3d47658c4487c26490d8`.
- Used the existing hash-checked, test-only `reviewed_release.read()`
  helper to read all 29 modified release files, their 29 parent blobs
  and all nine newly added release files directly from the pinned Git
  revision. Verified the adapter's exact Git blob digests, byte-for-byte
  predecessor reconstruction, string views, path forms and idempotence.
- Tested unreviewed mutations against both original release bytes and
  today's current bytes. Later independent changes remain visible and
  cannot be silently normalized into the historical fixture.
- Ran the old file-inventory contract against temporary exact release
  copies instead of today's source files. Exact additions are removed
  for list and tuple inputs; altered copies remain included.
- Verified six original public routes and the two newly added guide and
  download routes. Only an exact successful historical response is
  removed or reversed, and unknown content or HTTP failures survive.

Only the optional historical test and this sprint report changed. No
current guide, public HTML, dates, RSS, sitemap, local audit download,
source adapter, GitHub Actions, cron job or paid API was changed.
