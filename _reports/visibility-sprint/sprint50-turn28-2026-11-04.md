## Corrected site-maintenance misinformation

The site README described a live `Site checks` workflow, automatically generated IndexNow notifications on push, and Actions artifacts. This was outdated. The repository's authoritative `AGENTS.md` states that the old site workflow was intentionally removed on November 1 and forbids GitHub Actions, cron, other scheduled CI or paid API additions.

The revised README now explains:

- Build from `_source/` and generate public HTML with `python _scripts/build.py`.
- Run `--check`, `_scripts/check_search.py`, `_tests/check_html5.py` and the relevant local unit/browser suites. Do not claim they passed if not executed.
- Check public deployment with manually invoked `_scripts/check_live.py`; GitHub Pages may run provider-managed deployment tasks independently of repository-authored workflows.
- Treat `_scripts/submit_indexnow.py` as a **manual assessment tool** with no default submission; submitting public URLs requires separate owner authorization. No automated indexing notifier is present or requested.
- Keep past release receipts as historical evidence, not an invitation to reenable workflows.

The rest of the detailed site and Poker course implementation notes are retained below the new README entry. No production HTML, canonical URLs, RSS, sitemap, image, CSS, or JSON-LD identity assets changed in the website repository.

## How the three website goals benefit

**Search and generative AI visibility:** Public project READMEs link to the relevant original cases and to the consistent named author. These are relevant public citations readers can follow. GitHub links are not a guarantee of indexing, better positions, or citations in generative results.

**Credibility:** A person arriving at the website repository can now inspect specific work instead of needing to read engineering notes first. The old automatic-CI claims, which could mislead visitors about current verification, are corrected. Cases state their unknowns rather than inflating evidence.

**Association with real-life AI and interests:** The repository's public introduction connects small-business AI, writing/creative work, accounting research, and tournament poker to one author without portraying scholarly coauthorship as AI research or tournament prizes as profit.
