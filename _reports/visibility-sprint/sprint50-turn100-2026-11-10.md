# Turn 100: A shorter mobile path to the practical first step

Date: November 10, 2026

Baseline: `a967afdefeb28c14303991fe2215bdff85e9da0d`

## Reader problem

Turn 99 moved the useful starting choices ahead of the large project gallery,
after the three public evidence records. The published desktop homepage now
shows that intended order. At 900 pixels and below, the evidence grid becomes
one column, so a phone or tablet reader can encounter three longer records
before reaching the first free tool. This follows from the source's responsive
rules. It is not measured user scrolling, conversion or search behavior.

## Improvement

- Added a native, context-specific link immediately below the existing hero
  actions: "Want to try something now? Jump to a free tool and examples".
  It points to the actual heading of the existing three-choice section.
- Scoped the shortcut to widths of 900 pixels or less, exactly when the
  evidence cards stack vertically. Desktop visitors retain the original
  introductory layout, without another visible call to action.
- Gave the link a minimum 44-pixel touch target, a visible focus treatment,
  and natural line wrapping. It works as an ordinary fragment without
  JavaScript, accounts, tracking or external services.
- Preserved the five established hero actions and their order, the evidence
  records, three practical choices, case boundaries, project gallery, all
  source URLs, canonical page, identity metadata, and original content dates.
- Added four source, build, CSS and negative-control regression tests to
  `_tests/test_turn100_mobile_start_shortcut.py` and registered the suite in
  the local release checklist.

This is a discoverability adjustment. Its usefulness still requires actual
reader feedback or appropriately obtained aggregate measurement.
