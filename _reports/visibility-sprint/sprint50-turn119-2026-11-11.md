# Turn 119: Keep fallback Copy guidance synchronized with selection

Date: November 11, 2026

Baseline: `c596dc8298f193bd077c346b122c1de42f8e8abf`

## Observed reader problem

Turn 118 placed native Copy instructions beside the alternate export
buttons on the public AI Task Brief page. In connected Chrome at **160 by
568 CSS pixels**, a fictional assembled brief initially had the full
**1,454 of 1,454 characters** selected. Pressing the left arrow then
collapsed that selection to **0 of 1,454**. The separate cue and status
correctly warned that the full brief was no longer selected, but the
fallback panel still showed the initial **“Selected, not copied”**
instruction. That same panel also failed to reflect a detected native
Copy command. A reader returning to its controls could see stale advice.

The browser extension's Ctrl+plus and Ctrl+equals attempts did not
change the measured text or viewport metrics. This remains a narrow
reflow observation, **not** a genuine 200% zoom or font-size result.

## Improvement

- Keep the existing, source-rendered **“Selected, not copied. Ctrl+C,
  Cmd+C, or touch Copy.”** heading for initial or restored selection.
- On an incomplete selection, change the same accessible fallback group
  heading to **“Full brief no longer selected. Choose Select text manually
  again.”** This is an instruction, not a clipboard claim.
- When a native Copy event is detected with the full brief selected,
  change that heading to **“Copy command detected. Paste elsewhere to
  verify.”** The page never equates a Copy event with confirmed clipboard
  contents.
- Reset the heading on a new manual selection, export route, edited
  entry or cleared result. Only fixed UI strings are rendered with DOM
  text nodes. The brief body and its content remain untouched.
- Add three targeted tests, including a Node-based event simulation, and
  extend the optional 200% browser harness to test the partial-selection
  warning and manual re-selection. Register the new test in the manually
  invoked full local release checklist.

No browser clipboard reads, network calls, tracking, persistent storage,
new services, or scheduled workflows were introduced. Existing 44px
action targets, Save/Print routes, selection/focus behavior, accessible
group label, page URL and November 11 content revision date are retained.
