# Turn 65: Keep Nolan Kido's Resources page readable at enlarged text

Date: November 7, 2026

Baseline: `ea42da334017f0b820ee4b65502ec13824744241`

## Observed problem

The `/resources/` page is a practical gateway to Nolan Kido's original AI worksheets, decision records, poker guides and creative work. Its native links help readers connect the author's name with documented work in those interests.

At a 320-pixel viewport with a 200% root text size and additional character, word and line spacing, the shared mobile navigation allocated only **85 pixels** to each of its three columns. The visible **Technology**, **Living Well**, **Creative Work** and **Contact** labels required 141, 158, 186 and 99 pixels respectively. The labels exceeded their cells and could collide with neighbors, even though the document did not scroll horizontally. At 620 pixels the same pattern remained. These are offline layout measurements, not analytics.

At 768 pixels with enlarged text, some narrow section labels also exceeded the width of their metadata columns. The page had no dedicated styles for this reading state. The existing resource and worksheet links are native fragments, so a taller wrapped navigation header also needs enough scroll clearance to reveal their destinations.

## Focused improvement

- Add `assets/resources-reader.css`, scoped to `.page-resources`, rather than changing the shared navigation stylesheet used by the rest of the site.
- Allow the page's section labels to wrap inside their metadata columns.
- At mobile widths up to 620 pixels, use a naturally wrapping flex navigation while preserving all six original link labels, order and destinations. Allow the NK mark to grow with the enlarged type.
- Supply a mobile scroll margin for the four resource collections, thinking worksheets and the three original worksheet deep links. This complements the site's existing scroll padding and leaves the target visible beneath the taller sticky header.
- Register the new stylesheet only on the Resources page in the deterministic generator and in the read-only public-byte target inventory. Add an offline Chromium regression for layout, keyboard fragments and worksheet bookmarks.

No source copy, author identity, professional claims, SEO titles, descriptions, dates, JSON-LD, visible resource lists, sitemap or feeds were edited. The rebuilt `resources/index.html` changes only by one new versioned stylesheet link. Other generated HTML pages remain unchanged.
