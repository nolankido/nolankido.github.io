# Turn 144: Make horizontally scrollable evidence tables discoverable

Date: November 12, 2026

Baseline: `caa157adb76ee5045f8cecba64dc288c07aba20a`

## Observed problem

Preflight's benchmark table and Review Reply Writer's two recorded-result
tables use `.project-table-scroll`, which permits horizontal scrolling and
keyboard focus. Its shared table rule sets `min-width: 38rem`. On a
320-pixel-wide screen, the table necessarily exceeds its reading column;
some columns begin beyond the visible edge. The original pages had no
instruction telling a reader that more columns are available, despite
the results being important qualifications to the projects' claims.

This is a structural and discoverability issue. It is not evidence that
visitors failed to find the columns, or that adding instructions changes
their behavior.

## Improvement

- Add a brief visible instruction immediately before each of the three
  recorded-results tables. Explain that phone readers can swipe sideways
  and keyboard readers can focus the region and use arrow keys.
- Give each instruction a unique ID and connect its existing named,
  focusable table region using `aria-describedby`. Preserve the table's
  caption, headers, entries, original source links and tab focus.
- Style the instructions only on the Preflight and Review Reply Writer
  case pages, using their existing content-hashed stylesheet. Omit these
  screen-specific instructions from printed output.
- Add four dependency-free regression checks with mutation controls,
  plus a local-only Playwright script covering two script modes, four
  viewport widths, horizontal overflow, keyboard scrolling, print
  visibility and document overflow. Register the Python checks in the
  existing local release checklist. No new network or CI workflow.
- Regenerate source-owned public HTML and the other users of the
  stylesheet's changed content hash, including the two independently
  built AI articles. No case assertion, canonical URL, content date,
  sitemap entry, author identity or machine-readable claim changed.
