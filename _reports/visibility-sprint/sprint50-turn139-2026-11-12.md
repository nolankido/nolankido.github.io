# Turn 139: Retire obsolete release workflow instructions

Date: November 12, 2026

Baseline: `46ef0298ba2c6def8dfbf4dcd0a31ce1b3c66110`

## Observed contradiction

The current [AGENTS.md](../../AGENTS.md) forbids restoring, running or
relying on GitHub Actions, other CI services or scheduled bots. Its
`.github/workflows/site-checks.yml` workflow was intentionally removed on
November 1, 2026. Two active top-level maintenance guides still referred
to an ordinary Site checks workflow as if it existed:

- [ANALYTICS.md](../../ANALYTICS.md), in its maintenance instructions.
- [POKER_WORKSHOPS_RELEASE.md](../../POKER_WORKSHOPS_RELEASE.md), in its
  release verification instructions.

Those statements could misdirect a future maintainer or coding agent into
seeking, reactivating or extending an intentionally retired workflow.
Historical test descriptions and publication dates are not the problem.

## Improvement

- Replace the outdated workflow sentence in `ANALYTICS.md` with the
  current local release command, optional local browser checks, and direct
  public GET verification. Retain the existing privacy and measurement limits.
- Replace the stale integration-workflow instructions in
  `POKER_WORKSHOPS_RELEASE.md` with an explicit historical note and the
  same local-only release requirements. Retain its October 6 release date,
  source scope, and independent test descriptions.
- Keep `AGENTS.md` as the authoritative current policy. Add no workflow,
  schedule, tracker, public site page, search markup or paid dependency.

## Verification and limits

- GitHub source readback confirmed both edited files contain the local
  `python _scripts/local_release_checks.py` instruction, no longer direct
  the user to keep the old Site checks workflow read-only, and retain their
  original release context.
- GitHub compare showed **two changed Markdown files only** in the reviewed
  branch. No generated HTML, sitemap, CSS, JavaScript, source article or
  site routing file was changed.
- The local execution environment failed to start. Accordingly, no local
  Python release suite, deterministic site build, or browser test ran in this
  turn. These are documentation-only changes with connector-side source
  comparison, not a claim of a full local release pass.
- Search Console opportunity metrics were unavailable; no paid service was
  started. This change addresses a verified maintenance contradiction,
  not measured search traffic or visitor behavior.
