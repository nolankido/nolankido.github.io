# 50-hour visibility sprint: Turn 48 release record

Date: 2026-11-05

## Goal and boundary

Make the public offline Search Console example usable by a visitor who has no verified property or private export. The public demonstration must not be mistaken for a real traffic measurement, a search improvement, or a general-purpose checker for another website.

## Visitor-facing change

- Added [synthetic Pages](../../downloads/gsc-synthetic-pages.csv) and [synthetic Dates](../../downloads/gsc-synthetic-dates.csv) CSV downloads. Every row explicitly carries `Synthetic=YES`. All clicks and impressions are invented.
- Added an exact Windows command to the existing [Technology walkthrough](../../technology/#free-visibility-check), with the two CSVs saved beside the existing local Python checker.
- Explained the deliberately divergent totals: the complete fictional 31-day chart yields 62 clicks and 3,100 impressions, whereas the three fictional page rows yield only 22 clicks. The demonstration is about the distinction between whole-property chart totals and potentially limited page rows, not reported performance.
- Explicitly stated that query metrics are unavailable when the optional export is absent, that the local tool prints its privacy warning for actual exports, and that its current hostname and section rules recognize only `nolankido.com`.
- Recorded the example and its privacy boundary in the [SEO/GEO measurement protocol](seo-geo-measurement-v1.md).
- Added six regression tests for the public example and wired them into the manual local release checker. No GitHub Actions, cron jobs, scheduled workflows, external APIs, private exports or paid calls were introduced.

## Verification before release

- The unchanged published Python checker accepted the exact two samples for October 2026: `chart_export.calendar_days_validated=true`, 31 dates, 62 property clicks, 3,100 property impressions, 12 Technology page-row clicks, 7 Poker and 3 Other.
- All 6 new synthetic-example tests passed, including missing-day and wrong-date-format rejection, explicit fiction markers, absence of raw page URLs in the JSON, and matching source/published page markup.
- All 16 pre-existing checker tests passed without a checker-code change.
- Compiled the checker, the release-check runner and the new tests with Python's syntax checker.
- Confirmed by inverse Git blob comparisons that the Technology source and generated page differ from their base versions only by the three intended added HTML lines, and the release runner only by one new test entry.
- This workspace held a staged subset, not a full repository checkout. The complete site build, all historical release checks and browser suite were **not** run here. Public deployment verification is recorded separately below.

## Claims that remain unverified

No actual Search Console results were accessed or published. This change has not demonstrated new search clicks, stronger rankings, indexing, AI citations, conversion improvements or reader satisfaction. Those require later first-party measurement against a stable baseline.
