Baseline: `1dd13401344d593a07ff41988d3a49cdee8c418c`

## Observed issue

The optional `_tests/test_turn11_video_discovery_history.py` module
reported 14 failed assertions across two tests. It tried to derive the
November 3 public-video discovery release by partially reversing some
newer Poker, player-profile, site-search and historical-test edits in
today's files. The exact historical adapter correctly declined to
rewrite bytes that did not match the original successor Git hashes.
This fixture problem was not evidence that current public video links
or poker companions had regressed.

## Correction

- Anchored the original Turn 11 public-video discovery commit
  `0122add1160f88dd3ef48024067f6fbd77cbbf37` and its direct parent
  `778b76c814a33ee251a44b0bbccb18deb9710acf`, with original trees
  `2540b122250a2d12bbb03429564cda61580cd2d5` and
  `95b6a22c12b7a3a7a3b3070d5c6f7e0ad4110aba` respectively.
- Read all 22 modified release files and their 22 predecessors through
  the test-only, hash-checked `_tests/reviewed_release.py` fixture
  helper. Verified each successor and predecessor Git blob digest,
  exact restoration, idempotence, relative and absolute path views,
  and UTF-8 string output.
- Tested unknown mutations using both the original release bytes and
  today's bytes so subsequent reviewed edits are never erased to make
  historical fixtures appear to match.

Only `_tests/test_turn11_video_discovery_history.py` and this public
sprint report changed. Current player-profile and Poker URLs, video
labels, standalone companions, content dates, metadata, source files,
feeds, sitemap and predecessor adapters were not modified. No GitHub
Actions, cron, paid APIs or new CI system were used or introduced.
