# Visibility sprint Turn 160: Reliable local Chromium and honest browser-test provenance

Date: November 16, 2026 (America/Phoenix)
Main baseline: `eeff38091fde23841c0187f5e6a752908e476bac`

## Why this matters

The network-free Playwright test added in Turn 159 can render and test full HTML
pages without an HTTP origin. However, a reproducible browser-start failure
occurred in the current local testing environment:

```text
BrowserType.launch: Executable doesn't exist at .../chromium_headless_shell-1200/...
```

Playwright's managed headless browser was not installed, even though working
system Chromium was available at `/usr/bin/chromium`. Passing
`CHROMIUM_PATH=/usr/bin/chromium` fixed the test.

A second validity issue was more important: the old browser script could
report `12/12` checks against a synthetic fixture without clearly identifying
the fixture root, which might be mistaken for a test of the production source
pages. Turn 160 makes that distinction explicit and verifiable.

## Changes implemented

### Browser executable selection

The in-memory test now selects Chromium in this order:

1. Use an explicit `CHROMIUM_PATH`, failing early with a specific
   `FileNotFoundError` if that file does not exist.
2. Otherwise search installed system executables in this order:
   `chromium`, `chromium-browser`, `google-chrome`,
   `google-chrome-stable`.
3. Fall back to Playwright's managed browser only when none is found.

The chosen executable path appears in the JSON report.

### Prevent confusing fixture tests with repository tests

Added `repository_identity()`:

- Checks for the actual repository marker and source/build files:
  `AGENTS.md`, `_source/pages.json`, `_scripts/build.py`,
  `_scripts/build_poker_episode.py`, and
  `_scripts/build_standoff_episode.py`.
- If these are present, requires both standalone companions' authored
  source bodies to be embedded **exactly once** in the corresponding
  published HTML files. A missing or mismatched source fails.
- Reports `root_type` as either `checked_out_repository` or
  `synthetic_or_incomplete_fixture`, and reports whether
  `source_ownership_checked` passed.
- Records a SHA-256 checksum for each of the four tested HTML pages.
  These identify precisely which page bytes were rendered.
- Always reports `production_deployment_checked: false`.
  Rendering committed files does not check the live hosting service.
- Reports `synthetic_fixture_smoke_pass` for incomplete roots and
  `checked_out_repository_render_pass` only for validated checkouts.
- Setting `POKER_BROWSER_REQUIRE_REPO=1` rejects a fixture root
  **before** launching Chromium.

No production page, hand text, stylesheet, publication metadata, sitemap,
RSS feed or developer build process changed.

### Tests and release checklist

New `_tests/test_turn160_browser_provenance.py` has 3 Python regression
tests. To avoid requiring Playwright for every routine local release, it
parses the real browser script and exercises the executable-independent
provenance and browser-selection helpers directly. The tests cover:

- explicit and missing `CHROMIUM_PATH`;
- system Chromium discovery and no installed system browser;
- fixture-root labeling, page hashes and `production_deployment_checked`;
- strict refusal to report a fixture as a full repository pass;
- acceptance of a source-validated mock checkout;
- rejection of a companion with source/published mismatch;
- preservation of the blocked-network test structure.

Registered the module in the existing manually invoked local release
checklist. No GitHub Actions, scheduled workflow, CI server, paid API or
new online service was added.

## Results actually obtained

### Executed locally

- **Original runner with no browser override:** failed to launch because
  Playwright's managed headless shell was missing.
- **Original runner with `CHROMIUM_PATH=/usr/bin/chromium`:**
  passed 12/12 fixture layout checks, 12/12 keyboard paths and 12/12
  separately rendered guide-target checks, with zero network responses.
- **Updated runner without an override:** now automatically finds
  `/usr/bin/chromium` and passes the same 12 + 12 + 12 fixture checks.
  Its report correctly labels the root
  `synthetic_or_incomplete_fixture`, not a repository checkout.
- **Strict fixture refusal:** `POKER_BROWSER_REQUIRE_REPO=1`
  produced the intended nonzero exit and explicit fixture-root error.
- **Invalid explicit browser path:** also produced the intended nonzero
  exit and readable `CHROMIUM_PATH does not exist` error.
- **New Python regression suite:** 3 tests executed, 3 passed.
- **Python syntax:** new browser module compiled successfully.

### Not executed

- The complete Turn 159 browser suite against **all four actual,
  full-size, committed site pages and their CSS assets**.
  The container cannot clone or download GitHub (DNS disabled), while
  the connected GitHub repository is available through the connector
  but is not mounted as a local checkout.
- Full historical Python test suites and real-device assistive-technology
  testing, including screen readers.
- Production traffic, conversion, retention or search visibility analysis.

Fixture results do **not** certify the live site's mobile layout or
complete keyboard journey.

## Reproduce on the workstation checkout

```sh
python -m unittest discover -s _tests -p 'test_turn160_browser_provenance.py' -v
POKER_BROWSER_REQUIRE_REPO=1 python _tests/poker_hand_review_content_browser.py
python _scripts/local_release_checks.py --browser
```

On Windows PowerShell, the strict full-checkout equivalent is:

```powershell
$env:POKER_BROWSER_REQUIRE_REPO = "1"
python _tests/poker_hand_review_content_browser.py
```

The runner will automatically discover an installed Chromium executable
where available. Set `CHROMIUM_PATH` only if its location is unusual.
