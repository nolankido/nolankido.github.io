# Turn 143: Make project evidence shortcuts usable on narrow screens

Date: November 12, 2026

Baseline: `714f589ae82326e24d2c7e7e667afb977da21796`

## Observed problem

The three recorded AI project pages already include carefully authored links
to their example, method and limits. They do not load `entrypoints.css`,
which styles similar links elsewhere on the site. The existing shortcuts
were adjacent inline links inside a generic `div`, with no named navigation
landmark, spacing system or minimum link height.

In a direct live Chrome check at a 320-pixel viewport, Preflight's shortcuts
were rendered with `display: block`; the links wrapped as inline text. The
first observation included 21-pixel-tall link rectangles, and a later font
settling observation showed the same awkward wrapping across multiple lines.
This is a direct usability observation, not evidence about visitor traffic.

## Improvement

- Promote the existing shortcut group on Preflight, Dinner on Time and Review
  Reply Writer into a named `Project shortcuts` navigation landmark. Include
  a short visible `Explore this case` label.
- Preserve every authored link title, fragment destination and matching
  section heading. No case-study assertion, underlying evidence, factual
  result or publication date changes.
- Add a style scoped exclusively to these three project pages in the
  stylesheet they already load. It uses a wrapping grid with a safe narrow
  column width, clear spacing, a minimum **44-pixel link height**, and a
  visible keyboard focus outline. Hide the redundant shortcuts in print.
- Regenerate the three cases and the other consumers of the stylesheet's
  content-hashed URL, including two independently built articles. This
  refreshes the asset version without changing those other articles' prose.
- Register five new automated regression checks in the existing local
  release suite. They cover exact destinations, accessible naming,
  containment, responsive styling, provenance, and mutations that must fail.
