# Turn 19 independent engineering pass: easier task-brief disclosures

Prepared October 24, 2026 Pacific. The original website-growth plan's Turn 19 requires consenting visitor observations. Study [NK-UTILITY-01](https://github.com/nolankido/nolankido.github.io/issues/123) remains open, with no real participant attempts established by this change. This is a bounded accessibility improvement, not a claim that the visitor-study milestone is complete.

## Problem and scope

The existing AI Task Brief Builder offers a four-step meeting walkthrough, six explicitly fictional examples, and a no-script blank template in native `<details>` elements. Their summary rules specified only 28 pixels of minimum height. That leaves short labels with smaller activation areas on touch devices than the surrounding 44-pixel form controls. The markup and keyboard interactions already work.

## Repair

Keep the native summary marker, semantic HTML, existing copy, templates, field behavior and data-privacy boundary. Increase only those Task Brief disclosure hit areas to a 44-pixel minimum, with balanced vertical padding. Do not change global navigation, URLs, downloaded template bytes, publication metadata, site analytics, persistence, or any other public page.

Extend the existing real-browser Task Brief suite to measure all example/template summaries at 320, 390, 768 and 1440-pixel widths. The same suite must still open the walkthrough using Enter, retain an in-progress draft, survive enlarged spacing, exercise no-script fallbacks and prevent document overflow. Sitewide source regeneration and strict historical-release checks remain required; do not rewrite old baseline results.

## Evidence boundary

The final-head pull-request checks, code review, merge and public deployment receipts establish code/release status. Synthetic tasks, browser automation and CSS geometry cannot replace a person's comprehension or manual accessibility review. The planned moderated rounds, first-use assistance records and fresh-participant retests remain pending appropriate recruitment, consent and private evidence handling.
